克卜勒第一定律（軌道定律）
所有行星繞太陽運行的軌道都是橢圓，太陽位於橢圓的一個焦點上。

橢圓的名詞

  • 焦點 F₁、F₂：橢圓上任一點到兩焦點的距離和為定值，r₁ + r₂ = 2a。太陽在其中一個焦點，另一個焦點是空的。
  • 中心 O：兩焦點連線的中點。
  • 長軸 2a、半長軸 a；短軸 2b、半短軸 b。
  • 焦距 c：中心到焦點的距離，滿足 a² = b² + c²。
  • 離心率 e = c / a，0 ≤ e < 1；e = 0 時兩焦點重合，橢圓變成圓。
  • 近日點距離 = a − c = a(1 − e)；遠日點距離 = a + c = a(1 + e)。

補充

  • 克卜勒分析第谷（Tycho Brahe）留下的火星觀測資料，於 1609 年在《新天文學》中發表第一、第二定律。
  • 大多數行星的離心率很小（地球約 0.017），軌道看起來幾乎是圓；動畫中把離心率放大，方便觀察。
克卜勒第二定律（等面積定律）
行星與太陽的連線，在相等的時間內掃過相等的面積。

重點

  • 面積速率為定值：ΔA / Δt = πab / T。
  • 近日點附近連線短，行星必須走得快；遠日點附近連線長，行星走得慢。
  • 在近日點與遠日點，速度與連線垂直：r近v近 = r遠v遠，所以 v近 / v遠 = (1 + e) / (1 − e)。

物理本質

  • 太陽對行星的引力永遠指向太陽（連心力），對太陽的力矩為零，所以行星的角動量 L 守恆。
  • 面積速率 ΔA / Δt = L / 2m，角動量守恆就等於面積速率固定。

生活中的例子

  • 地球約在 1 月初經過近日點、7 月初經過遠日點，所以北半球的「秋分→春分」比「春分→秋分」少了約一週。

動畫說明

  • 每一塊扇形都是經過相同時間 Δt = T / N 掃過的區域。形狀不同，但面積相同；弧長則不相等。
克卜勒第三定律（週期定律）
行星公轉週期 T 的平方，與軌道半長軸 a 的三次方成正比：T² / a³ = k（定值）。

重點

  • 以「年」為週期單位、「天文單位 AU」為距離單位時，太陽系所有行星的 k ≈ 1 年²/AU³。
  • k 只由中心天體決定。以圓軌道推導：GMm/r² = m(2π/T)²r，得 T²/r³ = 4π²/GM。
  • 繞地球運行的人造衛星與月球，有另一個共同的 k 值，約 9.90 × 10⁻¹⁴ s²/m³（太陽系為 2.97 × 10⁻¹⁹ s²/m³）。
  • 兩者的比值 k地 / k日 = M日 / M地 ≈ 3.33 × 10⁵。
  • 離中心天體越遠，週期越長，平均速率也越慢。

補充

  • 克卜勒於 1619 年在《世界的和諧》中發表第三定律。後來牛頓用萬有引力定律證明了三大定律。
  • 嚴格來說應寫成 T²/a³ = 4π²/G(M+m)；繞行天體質量遠小於中心天體時，可省略 m。
  • 動畫中各天體的軌道距離與週期都依真實比例；天體大小則放大顯示。
